03.01

Databases

A database organizes data and supports queries and updates. A durable database keeps committed data beyond an application restart.

  • Gain: Shared durable records survive an application restart.
  • Limit: Durability does not replace backups. Database access still needs permissions and a failure plan.

03.02

SQL vs NoSQL

SQL databases commonly model tables and relations. NoSQL covers several models, such as documents and key-value records.

  • Gain: A suitable model makes common queries and updates simpler.
  • Limit: NoSQL is not one product or guarantee. Check transactions, query needs, and constraints for the chosen database.

MongoDB: Data models and access patterns · Mermaid source

03.03

Database indexes (indexing)

An index is an extra data structure that helps a database locate records by a key, such as a short code.

  • Gain: A suitable index can avoid a full table scan for a selective query.
  • Limit: Indexes consume space and add write work. The database may choose a scan for a query that returns many rows.

03.04

Transactions

A transaction groups database changes into one unit. A commit accepts the unit; a rollback discards its changes.

  • Gain: A transaction prevents a partial transfer when a statement fails.
  • Limit: A local database transaction does not automatically include an email or another service. Isolation rules still matter.

03.05

Denormalisation

Denormalisation stores duplicate or precombined data so a frequent read needs fewer joins or requests.

  • Gain: The feed can read posts and author names from one data set.
  • Limit: Copies can be stale between updates. More copies mean more update work and more rules.

MongoDB: Duplicate data and consistency · Mermaid source

03.06

Blob storage

An object store keeps files as objects with keys and metadata. A key identifies the object within its container.

  • Gain: Large files can use storage that supports direct object upload and download.
  • Limit: The object write and database write are separate. A failure needs cleanup or a retry plan.
